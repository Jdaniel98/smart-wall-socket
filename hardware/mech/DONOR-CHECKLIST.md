# Donor socket: what to buy and measure

The donor's contacts and shutters go into our printed carriers. Its measurements set the outlet positions, the contact carriers and the rear-board pads. Work on a **new, never-wired socket** only.

## 1. What to buy

Buy **3 identical** unswitched twin sockets (2-gang, 13 A, no switches), all the same model. You'll need:
- one to take apart and measure;
- one to keep whole as a reference;
- one spare for the first carrier fit.

Pick the model on these points, in order:
1. **Certified:** marked BS 1363-2 (for example a BSI Kitemark or ASTA mark) or bought from a reputable brand. Check for the GSA mark too.
2. **Separate contacts:** the L, N and E contacts are separate metal parts, held by screws or clips, so they come out intact. Check through the back or the terminal openings if you can. Riveted into one moulding is a worse choice: the contacts can't come out without damage.
3. **Separate shutter:** a separate shutter part (one per outlet, or one bar) that is opened by the earth pin.
4. **Easy to buy again:** a brand you can buy again in Accra for DVT and more EVT units.

Photograph the shop label or packaging (brand, model number, markings) before you open it.

## 2. Tools

- Digital calipers (0.01 mm resolution is fine; give readings to 0.1 mm).
- A steel rule.
- A BS 1363 plug, for the pin-depth measurements.
- A phone camera. Put the rule in every photo, flat and in the same plane as the part.

## 3. Whole socket (before opening)

Photograph the front, back, both sides, top and bottom.

Measure:

| # | What | Value (mm) |
|---|---|---|
| A1 | Faceplate width × height | |
| A2 | Faceplate depth, from the front surface to the wall-side surface (how far it stands proud) | |
| A3 | Depth of the back moulding behind the wall surface (deepest point) | |
| A4 | Distance between the two earth-aperture centres (outlet pitch) | |
| A5 | Earth-aperture centre above the plate's centre line, left and right outlet | |
| A6 | Fixing-screw centres (should be 120.6) | |

## 4. With a plug inserted (still assembled)

Insert the plug fully into one outlet.

| # | What | Value (mm) |
|---|---|---|
| B1 | Plug face to the socket front surface (should be 0, plug flat) | |
| B2 | Pin length visible from the back, if any, or the deepest point you can see the pin reach | |

## 5. Taking it apart

Photograph every step, so the parts can go back the same way.

**For each outlet, the shutter:**

| # | What | Value (mm) |
|---|---|---|
| C1 | Outline (width × height × thickness) | |
| C2 | Travel when the earth pin opens it | |
| C3 | How it's held (in the front plate or the back moulding), and its spring | |

**For each contact (L, N and E), with photos from three sides:**

| # | What | L | N | E |
|---|---|---|---|---|
| D1 | Overall length × width × height | | | |
| D2 | Metal thickness | | | |
| D3 | Where the plug pin is gripped: distance from the socket's front surface, when assembled | | | |
| D4 | Position of the grip point relative to the earth-aperture centre (x, y) | | | |
| D5 | Terminal type (screw clamp, tab, rivet) and its position relative to the grip point | | | |
| D6 | How it's fixed in the moulding (screw, clip, rivet), with the hole positions | | | |

**Also:**
- **E1:** does the L contact connect to the L terminal through a brass strip that also feeds the other outlet? Most twin sockets link both outlets. Photograph the strip and its route.
- **E2:** where the earth contacts join the earth terminal(s).

## 6. What to send me

- the photos;

If something is hard to measure, a clear photo with the rule in frame is enough: I'll scale from it and mark the value as estimated until it's checked on a printed carrier.
